# Machine-learning workspace

This directory contains the CIC-IDS-2017 research workflow.

- `data/raw/` stores the immutable merged source dataset locally.
- `data/processed/` stores generated cleaned or transformed datasets.
- `notebooks/` contains numbered exploratory notebooks.
- `src/` is reserved for reusable code extracted from notebooks.
- `models/` stores generated model pipelines.
- `reports/figures/` stores generated visualizations.
- `archive/legacy/` preserves the previous experiment for reference only.

Generated data and models are intentionally ignored by Git.
